# Finding codes

Every step reports what it did, and what it couldn't do, as findings. A finding has a code from the closed list below, a severity, a message and a count. The archive's `findings.json` holds every finding of a build, and `CONVERSION_REPORT.md` groups them by code.

An `error` finding ends the build with status `error`. The report lists each `warning` under its open questions for a person to look at. An `info` finding records what a step did. A code whose severity is `varies` takes the severity of the issue it passes on, such as a GBIF or OBIS validator issue.

`edna2dwc findings` prints this table from the installed package, and `edna2dwc findings CODE` explains one code.
